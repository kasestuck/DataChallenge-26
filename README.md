# CQA Insight — TheGoldenDuo

Система оценки качества клиентских диалогов для Freedom Broker CQA Hackathon.
FastAPI и SQLite хранят диалоги, версии чек-листов, оценки с доказательствами и апелляции.
Интерфейс на HTML/CSS/ES modules работает без сборки. Языки диалогов: RU, KZ, EN.

## Установка

Python 3.11+. Из корня проекта в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
if (-not (Test-Path -LiteralPath '.env')) {
    Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
```

Существующий `.env` сохраняется. Для реальной оценки заполните в нём `MODEL_API_KEY`,
`META_BASE_URL` и `META_MODEL`; для загрузки набора по сети — `DATASET_API_URL` и
`DATASET_GROUP_ID`. Ключ хранится только на бэкенде. Проверка здоровья, импорт из файла,
расчёт баллов и тесты не требуют ключа модели. Зависимости закреплены точными версиями.

## Единый запуск

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

Откройте [интерфейс](http://127.0.0.1:8001/),
[Swagger](http://127.0.0.1:8001/docs) или
[проверку здоровья](http://127.0.0.1:8001/api/health).
Один процесс обслуживает REST API и интерфейс: корневой `index.html` и каталоги
`/assets`, `/css`, `/js`, `/src`. Остальные файлы репозитория через эту раздачу недоступны.
Если присутствует прежний каталог `frontend/`, используется он. Не запускайте
`http.server` из корня объединённого проекта с `.env` и базой данных.

## Реальные данные в интерфейсе

1. Нажмите «Начать работу» и выполните демонстрационный вход: непустые e-mail и пароль.
   Это Demo Auth, без проверки пароля и без контроля доступа.
2. В шапке Workspace переключите **«Демо» → «API»** и откройте раздел «Диалоги».
   «Демо» содержит вымышленные данные; режим «API» обращается к бэкенду и показывает
   ошибки без подмены результатами демо.
3. По умолчанию API расположен по адресу `http://localhost:8001/api`.
   Для обращения к тому же адресу, что и открытая страница, выполните в консоли браузера:

```javascript
localStorage.setItem('cqa-api-base', `${location.origin}/api`);
localStorage.setItem('cqa-api-mode', 'api');
location.reload();
```

URL-параметра, включающего API-режим, сейчас нет. Выбранный режим и адрес сохраняются
в localStorage для текущего origin; `localhost` и `127.0.0.1` имеют разные хранилища.
Ключ модели в браузер вводить не требуется. Для раздельного размещения интерфейса и
API разрешённые origins задаются через `CORS_ORIGINS` на бэкенде.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/list_models.py
.\.venv\Scripts\python.exe scripts/smoke_test.py
```

`pytest` использует тестовые модели; две диагностические команды обращаются к
провайдеру и требуют заполненного ключа. При пустом ключе диагностика должна
сообщить ошибку конфигурации. Успешный smoke test проверяет доступ к модели,
а качество оценок проверяется отдельно.

## Текущие ограничения интерфейса

- Импорт и фильтры UI рассчитаны на chat/call; произвольные каналы, включая email и
  WhatsApp, поддерживаются бэкендом через API.
- Переоценка из UI выполняет последовательные полные запросы. Batch, прогресс задач,
  частичная переоценка `criterion_ids` и AI-подсказка апелляции доступны через API,
  но пока не подключены к кнопкам интерфейса.
- Редактор чек-листа требует сумму весов 100, хотя бэкенд нормирует произвольную
  допустимую сумму. В UI задаются границы шкалы; условия `yes_text/no_text` исходного
  критерия сохраняются. Для полного изменения условий используйте API.
- Overview, операторы и привязка оператора не поддержаны бэкендом. Список оценок
  строится из последних результатов диалогов; пагинация и сортировка клиентские.
- Демонстрационный вход не защищает API. Проект предназначен для локального прототипа.
