## Границы изменения документации

Новая структура README сохраняет рабочую команду запуска, разделение Demo/API, инструкции импортов, ограничения UI, ссылку на контракт и правила официального экспорта. Исторические документы отдельного фронтенда отмечены как архивные; их полезный текст сохранён.

Не меняются: Python/JavaScript/HTML/CSS, промпты, зависимости, `.env`, SQLite, чек-лист по умолчанию и официальные `results/`. Коммит и push при подготовке этого обновления не выполняются. Финальная проверка пяти изменённых/созданных документов: 98 относительных ссылок разрешаются, 12 якорей существуют; 16 PowerShell-блоков проходят синтаксический разбор. Локальные секретные значения из `.env` и явные шаблоны токенов в этих документах не обнаружены. `git diff --check` проходит; индекс не меняется. Хэши `.env`, основной БД, seed и DEV JSON совпадают с началом задачи.

Чтобы убрать оставшиеся TBD, команда должна предоставить: тарифы с источником/датой/валютой, официальные контрольные данные и API-доступ, имена и подтверждённый вклад участников, согласованный Ground Truth. Для подтверждения браузерной регрессии нужно отдельно выполнить актуальный E2E.
