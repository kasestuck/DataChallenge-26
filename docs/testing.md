# Тестирование Frontend

Сборки и Node нет: тесты — страницы в браузере. Запуск: `python -m http.server 5180` из корня репозитория, открыть страницу **в видимой вкладке**
(в фоновой вкладке таймеры замедляются, тесты с iframe зависают). Итог — в `document.title` и `window.__…__`.

| Страница | Что проверяет | Результат (2026-11-07) |
|---|---|---|
| `tests/smoke.html` | Mock-слой данных, UI-компоненты, XSS-экранирование, паритет i18n, обход всех разделов ×3 языка ×2 ширины (1280/390, нет горизонтального скролла), поведение, утечки слушателей, ошибка API-режима | `SMOKE PASS 85/85` |
| `tests/adapters.html` | Unit: мапперы реального адаптера на фикстурах из контракта, round-trip чек-листа, HTTP-клиент (формат ошибок, таймаут, отмена, невалидный JSON, query), фасад режимов, паритет методов адаптеров | входит в прогон `?live=1` (отдельный счёт без live не фиксировался) |
| `tests/adapters.html?live=1` | + **живой Backend** `localhost:8001` (без модели): health, upload, фильтры, детали, чек-листы (новая версия, неизменность старой, 422), форматы ошибок | `ADAPTERS PASS 71/71 (live)` |
| `tests/e2e.html` | Сценарии A–E в Mock Mode кликами по настоящему приложению | `E2E PASS 37/37` |

Живые тесты изменяют БД Backend (создают диалоги `fe-live-*` и версии чек-листа): запускайте только на **тестовой** БД (`DATABASE_PATH=...`).

## Ручные/скриптовые проверки Stage 4

* Доступность: 0 контролов без имени и 0 `img` без `alt` на 7 маршрутах Workspace (Mock), один `h1` на странице, нет горизонтального скролла; модалки: `role=dialog`, `aria-modal`, фокус-ловушка, Escape, возврат фокуса (в e2e), `:focus-visible`, `prefers-reduced-motion` в CSS.
* Режим API против живого Backend: список диалогов, деталь, XSS-реплика отображается текстом, Операторы/Overview → сообщение «не поддерживается», Чек-листы → версии с Backend.
* Утечки: число DOM-узлов 1009 до и после 120 переходов между разделами.

## Чего тесты НЕ покрывают

* Реальные оценки, апелляции и решения на настоящей модели (нет ключа Meta AI).
* Автозапуск в CI, кросс-браузерность (проверялось только во встроенном браузере десктопного приложения), скринридеры.
